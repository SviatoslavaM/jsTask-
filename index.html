📘 Довідка: що потрібно знати

Хибні значення (falsy)

В умові хибними вважаються лише шість значень: false, 0, "", null, undefined, NaN. Усе інше істинне, навіть рядки "0" і "false".

&& та || повертають значення

Вони не завжди дають true/false, а повертають одне зі значень, яке порівнювали.

  • a && b: якщо a хибне, повертає a, інакше b.
  • a || b: якщо a істинне, повертає a, інакше b.
"Оля" && "Привіт"  // Привіт
0 && "Привіт"     // 0
"" || "гість"     // гість
?? — що це таке

?? (оператор null-злиття) бере значення зліва, а якщо там null або undefined, то значення справа. На відміну від ||, він не вважає порожніми 0, "" і false.

let score = 0;
console.log(score || "немає");  // немає (помилка!)
console.log(score ?? "немає");  // 0 (правильно)

Правило: ?? не можна змішувати з || чи && без дужок: (a ?? b) || c.

prompt і confirm: вводимо значення вручну

prompt("Питання") показує віконце з полем вводу й повертає введений рядок (а null, якщо натиснули «Скасувати»). Для числа обгорніть: Number(prompt("Скільки років?")).

confirm("Питання") показує віконце з кнопками «ОК» і «Скасувати» й повертає true (ОК) або false (Скасувати).

let age = Number(prompt("Скільки тобі років?"));
let hasTicket = confirm("Чи є квиток?");
console.log(age >= 18 && hasTicket);

Важливо: prompt і confirm працюють лише в браузері, а в терміналі з node їх немає. Тому створіть у папці два файли:

<!-- index.html -->
<script src="script.js"></script>

У script.js пишіть код. Відкрийте index.html через Live Server (розширення VS Code), віконця з’являться самі, а результат дивіться в консолі браузера (F12, вкладка Console).

Пріоритет операторів

Спочатку !, потім &&, потім ||. Тому в a || b && c спершу виконується b && c. Дужки змінюють порядок і роблять код зрозумілішим.

Тернарний оператор

Це скорочений if/else: умова ? якщо_так : якщо_ні. Обидві гілки обов’язкові, а результат можна покласти у змінну.

let word = n === 1 ? "котик" : "котики";
Оператор % (залишок від ділення)

7 % 2 дорівнює 1, 10 % 5 дорівнює 0. Якщо n % 3 === 0, число ділиться на 3 націло.

Як читати завдання. У блоці «Дано» перелічені змінні: що це за змінна і яке значення вона зберігає, написано в коментарі після //. Копіюйте блок на початок файлу, пишіть рішення нижче й змінюйте значення змінних, щоб перевірити різні випадки. Результат завжди виводьте через console.log(...).

Рівень 1. Розминка: логічні оператори

1. Передбач результат

Завдання: Змінних тут немає: кожен рядок вже містить готовий вираз. Спершу запиши свою відповідь для кожного рядка, потім запусти код і порівняй.

console.log(true && false);
console.log(true || false);
console.log(!true && false);
console.log(!(true && false));
console.log(5 > 3 && 2 > 10);
console.log("" || "гість");
console.log("Оля" && "Привіт");
console.log(0 || null || "порожньо");
console.log(1 && 2 && 3);
console.log(null ?? "за замовчуванням");
console.log(0 ?? "за замовчуванням");

Очікувано: кожен рядок виводить значення, а питання нижче допоможуть пояснити різницю.

Питання: чому 0 || "x" і 0 ?? "x" дають різне? Чому це важливо, якщо в грі гравець має 0 очок?

2. Охоронець нічного клубу

Дано (вставте на початок файлу):

let age = 20;         // вік гостя, число
let hasTicket = true; // чи є квиток: true — є, false — немає
let isVIP = false;    // чи VIP-гість: true — так, false — ні

Завдання: Напиши одну умову й виведи її результат: true — гостя пускають, false — ні. Пускають, якщо йому 18 або більше і (є квиток або він VIP). Перевір на 5 наборах значень і склади таблицю «age, hasTicket, isVIP → результат».

Очікувано: для наведених даних у консолі true. Для age = 17, hasTicket = true, isVIP = true має бути false.

ПідказкаЯкщо умова в тебе складається з двох частин різного типу (&& і ||), подумай про дужки.
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let age = Number(prompt("Скільки років гостю?"));
let hasTicket = confirm("Чи є квиток? (ОК — так, Скасувати — ні)");
let isVIP = confirm("Це VIP-гість?");

Рівень 2. Тернарний оператор

3. Світлофор

Дано (вставте на початок файлу):

let color = "red"; // колір світлофора: "red", "yellow" або "green"

Завдання: Через тернарний оператор виведи текст: для "red" — «Стій!», для "yellow" — «Приготуйся», для "green" — «Їдь!». Перевір усі три значення.

Очікувано: для "red" у консолі «Стій!».

ПідказкаТернарні можна вкладати: a ? x : b ? y : z. Подумай, чи залишається код читабельним.
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let color = prompt("Колір світлофора: red, yellow чи green?");

4. Рефакторинг

Дано (вставте на початок файлу):

let score = 75; // бали за тест, число від 0 до 100

Завдання: Нижче код з if/else. Перепиши його через тернарний оператор (одна змінна message, вивід через console.log(message)). Потім відповідай: що читається краще і чому?

let message;
if (score >= 90) {
  message = "Відмінно";
} else if (score >= 60) {
  message = "Добре";
} else {
  message = "Спробуй ще";
}
console.log(message);

Очікувано: 75 → «Добре», 95 → «Відмінно», 40 → «Спробуй ще».

Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let score = Number(prompt("Бали за тест (0–100):"));

5. Котики: відмінювання

Дано (вставте на початок файлу):

let n = 5; // кількість котиків, ціле число від 1 до 100

Завдання: Виведи в консоль фразу з правильним словом: 1 котик, 2 котики, 5 котиків. Крок 1: лише «котик» (n = 1) або «котики» (усі інші). Крок 2: врахуй числа 11–14 (котиків) і закінчення на 1 (котик), на 2–4 (котики). Використай &&, || і тернарний разом.

Очікувано: 1 → «1 котик», 2 → «2 котики», 5 → «5 котиків», 11 → «11 котиків», 21 → «21 котик», 24 → «24 котики».

Підказкаn % 10 — остання цифра числа, n % 100 — дві останні цифри.
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let n = Number(prompt("Скільки котиків?"));

Рівень 3. Міні-ігри та сценарії

6. Камінь-ножиці-папір

Дано (вставте на початок файлу):

let player = "rock";       // вибір гравця: "rock" (камінь), "scissors" (ножиці) або "paper" (папір)
let computer = "scissors"; // вибір комп'ютера: ті самі три варіанти

Завдання: Виведи результат: «Нічия», «Ти переміг» або «Комп'ютер переміг». Правила: камінь б'є ножиці, ножиці б'ють папір, папір б'є камінь. Використай лише логічні й тернарний оператори, без switch.

Очікувано: rock проти scissors → «Ти переміг», paper проти paper → «Нічия», scissors проти rock → «Комп'ютер переміг».

ПідказкаБонус: виведи рядок на кшталт «rock проти scissors: Ти переміг».
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let player = prompt("Твій вибір: rock, scissors чи paper?");
let computer = prompt("Вибір комп'ютера: rock, scissors чи paper?");

7. Перевірка пароля

Дано (вставте на початок файлу):

let length = 9;       // довжина пароля, кількість символів
let hasDigit = true;  // чи є в паролі цифра: true — є, false — немає
let hasUpper = false; // чи є в паролі велика літера: true — є, false — немає

Завдання: Три умови: (1) length не менше 8, (2) hasDigit дорівнює true, (3) hasUpper дорівнює true. Виведи «Надійний», якщо виконано всі три; «Середній», якщо виконано рівно дві; «Слабкий», якщо одна або жодної.

Очікувано: 9, true, false → «Середній»; 12, true, true → «Надійний»; 5, false, false → «Слабкий».

ПідказкаУ JavaScript true + true дорівнює 2, тож умови можна порахувати.
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let pwd = prompt("Введи пароль:");
let length = pwd.length;
let hasDigit = confirm("Є в паролі цифра?");
let hasUpper = confirm("Є велика літера?");

8. Кіноафіша

Дано (вставте на початок файлу):

let age = 16;          // вік глядача, число
let hasAdult = true;   // чи є поруч дорослий: true — є, false — немає

let balance = 120;     // скільки грошей у глядача, грн
let price = 150;       // повна ціна квитка на фільм 16+, грн

Завдання: Правила: фільм 16+ можна дивитися, якщо вік не менше 16 або (вік не менше 12 і поруч є дорослий). Студент платить на 20% менше. Виведи одне з повідомлень: «Квиток куплено за X грн», «Недостатньо коштів» або «Вік не підходить». Реалізуй через тернарні оператори, потім перепиши з if/else і порівняй.

Очікувано: для наведених даних — «Квиток куплено за 120 грн». Для age = 10 — «Вік не підходить», для balance = 100 — «Недостатньо коштів».

ПідказкаСпочатку обчисли ціну зі знижкою у змінну finalPrice, а умову перегляду винеси в canWatch.

Рівень 4. Челенджі для сильних

9. Ловимо баги з коротким замиканням

Дано (вставте на початок файлу):

let score = 0; // очки гравця: 0 — нормальне значення (грав, але набрав 0), undefined або null — гравець ще не грав

Завдання: Код console.log("Очки: " + (score || "ще не грав")); при score = 0 виводить «ще не грав». Поясни, чому це помилка, і виправ одним оператором. Перевір чотири значення: 0, 15, undefined, null.

Очікувано: 0 → «Очки: 0», 15 → «Очки: 15», undefined і null → «Очки: ще не грав».

ПідказкаДодатково: що виведе score && "є очки" при score = 0 і при score = 5?
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let input = prompt("Очки гравця (Скасувати — ще не грав):");
let score = input === null ? null : Number(input);

10. Високосний рік в один рядок

Дано (вставте на початок файлу):

let year = 2024; // рік, ціле число

Завдання: Рік високосний, якщо ділиться на 4, але не ділиться на 100, окрім випадків, коли ділиться на 400. Виведи true або false одним виразом, без if.

Очікувано: 1900 → false, 2000 → true, 2024 → true, 2100 → false.

Підказкаyear % 4 === 0 означає, що рік ділиться на 4 націло.

11. FizzBuzz 2.0

Дано (вставте на початок файлу):

let n = 15; // число, яке перевіряємо

Завдання: Виведи «Fizz», якщо n ділиться на 3; «Buzz», якщо ділиться на 5; «FizzBuzz», якщо ділиться на обидва; інакше виведи саме число. Спочатку розв'яжи вкладеними тернарними, потім спробуй варіант із || і поясни, як він працює.

Очікувано: 3 → «Fizz», 5 → «Buzz», 15 → «FizzBuzz», 7 → 7.

ПідказкаВаріант для пояснення: (n % 3 ? "" : "Fizz") + (n % 5 ? "" : "Buzz") || n.
Ввести значення через prompt і confirm

Замість рядків «Дано» вставте це (запуск у браузері, див. довідку):

let n = Number(prompt("Введи число:"));
