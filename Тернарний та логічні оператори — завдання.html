JavaScript, 16–18 років. Читай умову на телефоні, а код пиши й запускай на комп’ютері у VS Code. Познач виконане завдання галочкою.

Виконано 0 з 11

Рівень 1. Розминка: логічні оператори

1. Передбач результат

Запиши, що виведе кожен рядок, і лише потім запусти.

console.log(true && false);
console.log(true || false);
console.log(!true && false);
console.log(!(true && false));
console.log(5 > 3 && 2 > 10);
console.log("" || "гість");
console.log("Оля" && "Привіт");
console.log(0 || null || "порожньо");
console.log(1 && 2 && 3);
console.log(null ?? "за замовчуванням");
console.log(0 ?? "за замовчуванням");

Питання: чому 0 || "x" і 0 ?? "x" дають різне? Чому це критично, якщо в грі 0 очок?

2. Охоронець нічного клубу

Змінні: age, hasTicket, isVIP. Пускають, якщо вік 18+ і (є квиток або VIP). Напиши одну умову та перевір її на 5 наборах даних. Склади таблицю «вхід → результат».

ПідказкаЗверни увагу на дужки: без них && виконається раніше за ||.

Рівень 2. Тернарний оператор

3. Світлофор

Змінна color = "red", "yellow" або "green". Через тернарний оператор виведи: «Стій!», «Приготуйся», «Їдь!».

ПідказкаТернарні можна вкладати: a ? x : b ? y : z. Але подумай, чи читабельно це.

4. Рефакторинг

Перепиши через тернарний оператор:

let message;
if (score >= 90) {
  message = "Відмінно";
} else if (score >= 60) {
  message = "Добре";
} else {
  message = "Спробуй ще";
}

Що читається краще: if/else чи тернарний варіант? Чому?

5. Котики: відмінювання

Функція pluralize(n) повертає: 1 котик, 2 котики, 5 котиків.

  • Крок 1: лише «1» або «більше».
  • Крок 2: врахуй 11–14 і закінчення на 1, 2–4. Використай &&, || і тернарний разом.
ПідказкаКорисні вирази: n % 10 і n % 100.

Рівень 3. Міні-ігри та сценарії

6. Камінь-ножиці-папір

Змінні player і computer: "rock", "scissors", "paper". Результат: «Нічия», «Ти переміг», «Комп’ютер переміг» — лише логічні й тернарний оператори, без switch.

Бонус: вибір комп’ютера через Math.random().

7. Перевірка пароля

Функція checkPassword(pwd) повертає:

  • «Надійний» — довжина ≥ 8 і є цифра і є велика літера;
  • «Середній» — виконано щонайменше дві умови з трьох;
  • «Слабкий» — інакше.
Підказка
/\d/.test(pwd)
pwd !== pwd.toLowerCase()
Булеві значення можна додавати: true + true === 2.

8. Кіноафіша

const user = { age: 16, hasParents: true, isStudent: true, balance: 120 };
const movie = { ageLimit: 16, price: 150 };
  • Фільм 16+ можна дивитися, якщо вік ≥ 16 або (вік ≥ 12 і є дорослий поруч).
  • Студент має знижку 20%.
  • Вивід: «Квиток куплено за X грн», «Недостатньо коштів» або «Вік не підходить».

Реалізуй через тернарні, потім перепиши через if/else і порівняй.

Рівень 4. Челенджі для сильних

9. Ловимо баги з коротким замиканням

const user = { name: "Іра" };
console.log(user.address.city);

Що не так? Напиши 3 способи безпечно отримати city: через &&, через ?., через ?. разом з ??.

10. Високосний рік в один рядок

Рік високосний, якщо ділиться на 4 і не ділиться на 100, окрім випадків, коли ділиться на 400. Напиши isLeap(year) одним виразом без if. Перевір: 1900, 2000, 2024, 2100.

11. FizzBuzz 2.0

Для чисел 1–50: кратне 3 → «Fizz», кратне 5 → «Buzz», кратне обом → «FizzBuzz», інакше саме число.

Спочатку через вкладені тернарні, потім спробуй такий варіант і поясни, як він працює:

(n % 3 ? "" : "Fizz") + (n % 5 ? "" : "Buzz") || n
